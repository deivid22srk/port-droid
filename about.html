Sobre o Hail Games

O port-droid é a vitrine oficial de ports do canal Hail Games (@Hail-Games1). A ideia é simples: reunir em um só lugar os melhores ports da comunidade para Android, com informação honesta sobre requisitos, instruções claras de instalação e links sempre apontando para quem realmente desenvolveu o trabalho.

Cada jogo do catálogo traz créditos do autor do port e do projeto original, além de avisos sobre o estado de desenvolvimento. Nada de links encurtados, mirrors duvidosos ou paywall — o que você baixa vem direto do repositório oficial no GitHub dos desenvolvedores.

1 · Escolha o jogo

Navegue pelo catálogo, filtre por categoria, chipset ou nível de desempenho e abra a página do port para ver todos os detalhes antes de baixar.

2 · Confira os requisitos

Cada port lista os requisitos mínimos e recomendados, o chipset ideal e quanto de armazenamento você vai precisar — tudo baseado na documentação oficial.

3 · Baixe e instale

O botão de download leva direto às releases oficiais no GitHub. Siga o passo a passo da página do jogo e, se travar, procure o tutorial no canal.

Dúvidas frequentes

Perguntas rápidas

Os downloads são seguros?

Os botões do site apontam para as páginas oficiais de releases dos repositórios dos autores no GitHub — não redistribuímos nenhum APK. Os projetos listados verificam assinatura e checksum (SHA-256) nas atualizações internas dos apps. Mesmo assim, baixe sempre pelos canais oficiais indicados em cada página.

Preciso de um celular potente?

Depende do port. Cada página traz os requisitos mínimos e recomendados reais: alguns ports rodam bem em aparelhos intermediários, outros pedem GPUs de topo como Adreno 7xx. Use o filtro de desempenho do catálogo para achar o que o seu aparelho aguenta.

O port-droid distribui os jogos?

Não. O site hospeda apenas imagens ilustrativas (substituíveis) e links. Os ports são projetos independentes com licenças próprias e o jogo original sempre deve vir da sua própria cópia legal — cada página deixa isso explícito.
